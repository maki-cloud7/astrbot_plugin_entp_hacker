# astrbot_plugin_entp_hacker

这是为 AstrBot 开发的 **ENTP极客挚友资讯聚合插件**。

## 简介
这个插件会像你的“极客挚友”一样，每天帮你满网冲浪，抓取最硬核的技术资讯和创业点子，包括：
- **X (Twitter)** 关注圈子的最新动态
- **GitHub Trending** 最热开源项目
- **Hacker News** 硅谷精选探讨
- **V2EX** 国内极客热议
- **Reddit** 热门极客与独立开发节点
- **Product Hunt** 每日最新产品发布

所有的生肉资讯抓取后，会强制喂给大模型进行阅读理解，最后它会以真诚、得体、充满创业洞察的 ENTP 人格向你分享它觉得最有趣的 1-2 条内容！

## 配置与使用
1. 在 AstrBot 管理面板的**插件配置**中，填入你的 X (Twitter) 网页端的 `auth_token` Cookie 值，以便它可以免 API 抓取推文。同时可以自定义想要抓取的 X 博主和 Reddit 节点。
2. 配置完成后，前往 **定时任务 (Cron Job)**，添加每天早晚的触发任务。
3. **定时任务提示词参考**：
   > “请使用 `get_geek_news` 工具去全网刷一下最新的极客资讯。仔细阅览后，挑 1-2 条最让你兴奋或有启发的内容跟我分享。请结合你真诚、得体的 ENTP 独立开发者视角，和我探讨其中的技术亮点或你想到的创业点子。”

## 依赖
本插件会在安装时自动安装以下依赖：
- `twikit`
- `httpx`
- `feedparser`
- `beautifulsoup4`
